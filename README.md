# ITTO 営業用モックアップ

土地・戸建て・区分マンションを中心とした不動産売買について、準備期間のオファーからオークション、優先交渉までを説明するための画面見本です。実際の審査、通知、入札、契約、決済は行いません。

## 見方

### 公開ページで見る

以下の「見本画面を開く」を押すと、ブラウザで確認できます。権限譲渡後の保存先である `dexel1114` の公式公開URLです。

**[見本画面を開く](https://dexel1114.github.io/itto-mockup/)**

**公開確認済み：** 2026年7月31日に、上記URLから見本画面を表示できることを事業責任者が確認しました。

変更を保存した直後は、画面への反映に数分かかる場合があります。その場合は少し待ってから、同じリンクをもう一度押してください。

2026年7月31日に、無料で見本画面を公開するため、この保存場所全体を公開する方針に決定しました。公開すると、画面だけでなく、このREADMEや`spec`フォルダの事業資料も第三者が閲覧できます。

初回公開は、次の順番で設定しました。

1. [保存場所の基本設定](https://github.com/dexel1114/itto-mockup/settings)を開き、最下部の「Danger Zone」にある「Change repository visibility」を押す。
2. 「Change visibility」から「Make public」を選び、画面の案内に沿って公開を確定する。
3. [公開設定画面](https://github.com/dexel1114/itto-mockup/settings/pages)を開き、「Source」から「GitHub Actions」を選ぶ。
4. 公開処理が終わるまで数分待ち、「見本画面を開く」を押す。

### 手元のファイルで見る

1. `index.html` をダブルクリックしてブラウザで開きます。
2. 最初の画面で「買主」「売主」「仲介会社」「ITTO運営」のいずれかを選びます。
3. ホーム画面の「確認できる画面」から、各立場の画面へ移動します。

インターネット接続がある場合は建物の見本写真が表示されます。接続がなくても、写真以外の画面と操作は確認できます。パソコンとスマートフォンのどちらの画面幅にも対応しています。

## ファイル

- `index.html`：最初に開く画面
- `styles.css`：色、文字、配置、スマートフォン表示
- `app.js`：固定の見本データと画面切り替え
- `.github/workflows/pages.yml`：画面見本を公開ページとして表示するための設定
- `spec/20-mockup-guide.md`：画面の役割と設計意図
- `spec/21-dummy-data.md`：見本データの説明

本番開発ではなく営業・説明用であるため、入力内容は保存されず、ボタンを押しても実際の取引は行われません。

この保存場所は `moto7070` から `dexel1114` へ権限譲渡されています。GitHub Pages（GitHub上でホームページを公開する機能）の設定は譲渡後の保存先で有効にする必要があります。無料公開のため保存場所全体を公開する方針は、公開範囲を説明したうえで事業責任者が選択しました。

2026年8月3日、実需中心のサービスであることに合わせ、物件例を2,000万円台から1億5,000万円程度を中心とする価格帯へ変更しました。「投資機会」という表現を使わず、土地・戸建て・区分マンションを中心に探せる入口へ修正しています。

2026年8月7日、検索に「都道府県から探す」「沿線から探す」、土地面積、駅徒歩を追加しました。土地以外には新耐震・旧耐震を表示し、「本人ページ」は「マイページ」へ変更しています。

土地面積は50㎡・75㎡・100㎡から、以降50㎡刻みで500㎡まで選択できます。駅徒歩は1分から20分まで1分刻みで選択し、それ以上を条件にしない場合は「指定なし」を使用します。

検索の市区町村は東京23区と多摩地区に分け、全23区と多摩26市・3町・1村を折りたたみ式のチェックボックスから選択できます。沿線もJR・東京メトロ・都営地下鉄・私鉄に分けました。見本物件は15件です。

トップは「不動産オークションのITTO」を中心にした明るい配色へ変更しました。マイページの「検討中」は、一般的な利用者向け表現の「お気に入り」へ変更しています。

物件一覧からお気に入り登録ができ、物件詳細の「オファーする」「入札する」から金額・オファーコメントの入力画面へ進めます。トップの初心者マークからは、ITTOオークションの参加方法を4段階で確認できます。

上部に閲覧履歴・メッセージ・ログインを追加しました。会員は物件ごとのお気に入り数と入札予定者数、個人情報登録済み会員はさらに価格を確認できます。初心者向け画面から新規会員登録へ進めます。

2026年8月7日、添付のブランドガイドに合わせ、ロゴをオークション画面のアイコンとITTOの文字へ変更しました。Montserrat ExtraBold／Noto Sans JP Black、ネイビー `#0F2942`、ミント `#4FD1C5`を全画面へ適用しています。

トップはビル写真をやめ、住宅・マンション・木・オークションを表す小さなイラストへ変更しました。ミントを主役にした明るく親しみやすい配色です。「オークション掲載物件数 NO.1」は削除し、その位置に参加者層を伝える説明文を表示します。

未ログイン時は「お気に入り数・入札予定者数は会員登録後に表示」と明記します。物件詳細からログインした個人情報登録済み会員は、対象物件の定型オファー／入札フォームへ戻り、金額・資金計画・希望時期・希望条件・コメントを入力できます。

トップ右側には、売却・購入の両方を扱うサービスであることが一目で分かるよう、「不動産を 売るならイット！」「不動産を 買うならイット！」の2つの案内カードを表示します。

トップのサブコピーは「価格は市場が決める。」、説明文は「初めての方でも安心して参加できる不動産市場」です。売却・購入カードはイラストより大きく表示し、スマートフォンではトップ内容の最上部へ配置します。

シンボルマーク内には「Auction」の文字を表示しません。トップ右側は「売るならイット！」「買うならイット！」を最優先で大きく見せ、イラストは小さな補助表示とします。

トップのメインキャッチは「オークションだから、価値が見える。」です。その直下に「価格は市場が決める。」を1行で表示します。

メインキャッチは「オークションだから、」で改行し、2行目の「価値」を強調します。スマートフォンでは「売るなら」「買うなら」の2枚の直下に表示します。

正式なブランドコピーは「オークションだから、価値が見える。」です。スマートフォンでは白い背景枠を使わず、売却・購入カード直下へコピーだけを大きく表示します。

トップの「希望条件を登録して物件を待つ。」から、会員情報と希望条件をまとめて入力する専用画面へ進めます。最初の登録後に、詳しい条件を任意で追加できます。

スマートフォンの物件一覧では、お気に入りマークを各物件カードの右上へ固定して、写真の幅に左右されず見つけやすくしています。オファーコメントの補足先は「売主（仲介会社）」と明記しています。

「はじめての方へ」の濃紺欄の見出しは「オークション終了後、条件を確認して契約へ。」です。スマートフォンでは「条件を確認して」の後で改行します。ヘッダーとフッターのシンボルマークは、パソコン・スマートフォンとも上のミント線と下の3マスが正方形の枠内へ完全に収まり、中央にそろうようにしています。

物件の販売状況は「まもなく開始／オークション中／終了」の3つで表示します。「まもなく開始」の物件には開始までの日数を示します。利用者の行動は「♡ お気に入り」と「入札予定に登録」に分け、気になる物件と参加意思のある物件を別々に扱います。物件詳細でも両方を登録でき、会員にはお気に入り数と入札予定者数を別々に表示します。終了物件の写真はグレーの網掛けで表示します。

「オークション中」のマークはオレンジ色にし、ネイビーの「まもなく開始」と見分けられるようにしています。ヘッダーとフッターは同じ完成形のシンボルを使用します。マイページのオファー確認では、掲載仲介会社から届いた返信に追加コメントを送り、送信後の未読・既読をメッセージ形式で確認できます。

マイページは「ITTO上の取引管理」画面として、上段に「お気に入り／入札予定／提出済みオファー／参加中の入札」を並べます。気になる段階から実際に競っている段階まで、買主の温度感を4段階で確認できます。入札予定は専用の物件一覧へ進み、提出済みオファーは「詳細・メッセージ」から、その物件の条件と掲載仲介会社とのやり取りを一度に確認できます。未確認のお知らせは上段から外し、右側のお知らせ欄から一覧へ進みます。

マイページの補足文は、提出済みオファーを「条件付きオファーを提出中」、参加中の入札を「オークションに参加中」と簡潔に表示します。物件カード右側は、お気に入り数と入札予定者数を縦に分け、オークション中の物件には実際の入札数も追加して表示します。

「はじめての方へ」のSTEP 4では、最高額入札者を第一候補として上位の複数名を優先交渉者に選定するところまで、参加の流れだけを案内します。 パソコンでは見出しを「最高額入札者から順に」と「優先交渉へ。」の2行で表示します。その下の濃紺欄では、価格以外の条件確認、売主・買主による購入条件の確認と合意、売買契約、売買代金の決済完了によるオークションの成約を、1文ずつ改行して説明します。

「希望条件を登録して物件を待つ。」と売却・購入カードの間隔を広げ、ボタンの高さもさらに大きくしました。パソコンとスマートフォンの両方で、3つの内容が詰まって見えず、希望条件登録を独立した次の行動として認識しやすい表示にしています。

## 2026年8月7日のスマートフォン登録ボタン配置

スマートフォンでは「希望条件を登録して物件を待つ。」を、ブランドコピー「オークションだから、価値が見える。」とITTOロゴの間へ移動しました。高さを104px以上にし、ブランドの説明を読んだ直後に希望条件登録へ進める大きな導線として表示します。パソコンでは売却・購入カード直下の配置を維持します。

## 2026年8月8日の希望条件登録フロー

トップ説明文を「初めての方でも安心して参加できる不動産市場」へ変更しました。スマートフォンの「希望条件を登録して物件を待つ。」は「登録して」の後で改行します。

トップのボタンから、会員情報と基本の希望条件を約1分で登録する専用画面へ進めます。登録完了後は、通知予定を伝えたうえで、駅徒歩・築年数・間取り・面積・利回り・融資事前審査・購入経験を任意で追加できます。最初からすべてを必須にせず、「会員＋基本条件」と「詳しい任意条件」の2段階に分けています。

## 2026年8月8日の詳しい希望条件の選択方法

登録完了後に追加できる駅徒歩、築年数、間取り、土地面積、建物面積、利回り、融資事前審査、購入経験は、すべてプルダウンから選べるようにしました。文字を入力する必要がなく、希望がない項目は「こだわらない」または「未選択」のまま先へ進めます。

## 2026年8月8日のブラウザバック対応

パソコンとスマートフォンで、ブラウザや端末に備わっている「戻る」「進む」操作から、モックアップ内で直前または次に見ていた画面へ移動できるようにしました。戻った際は以前の表示位置も復元します。ブラウザ標準の操作で戻れるため、先に追加したヘッダーの専用「← 戻る」ボタンは撤去しました。
