# ITTO 営業用モックアップ

一棟不動産の売却について、準備期間のオファーからオークション、条件比較、優先交渉、成約結果の記録までを説明するための画面見本です。実際の審査、通知、入札、契約、決済は行いません。

## 見方

### 公開ページで見る

GitHubの「Actions」で公開処理が完了すると、発行された公開ページのURLからブラウザで確認できます。初回は公開機能も自動で有効になるため、ダウンロードや専用ソフト、GitHub側の事前設定は不要です。

### 手元のファイルで見る

1. `index.html` をダブルクリックしてブラウザで開きます。
2. 最初の画面で「買主」「売主」「仲介会社」「ITTO運営」のいずれかを選びます。
3. ホーム画面の「確認できる画面」から、各立場の画面へ移動します。

インターネット接続がある場合は建物の見本写真が表示されます。接続がなくても、写真以外の画面と操作は確認できます。パソコンとスマートフォンのどちらの画面幅にも対応しています。

## 画面一覧

| 対象 | 主な画面 |
|---|---|
| 共通 | 利用者選択、会員登録・審査状況、お知らせ |
| 買主 | 物件一覧・詳細、問い合わせ、オファー、入札・即決、優先交渉への回答、参加履歴 |
| 売主 | 売却物件、掲載確認、条件比較、優先交渉相手の選択、問い合わせ、販売履歴 |
| 仲介会社 | 管理物件、物件・資料登録、プレビュー、問い合わせ対応、内部コメント、進行・成約結果 |
| ITTO運営 | 運営状況、買主・仲介会社審査、オークション監視、販売履歴 |

## ファイル

- `index.html`：最初に開く画面
- `styles.css`：色、文字、配置、スマートフォン表示
- `app.js`：固定の見本データと画面切り替え
- `.github/workflows/pages.yml`：画面見本を公開ページとして表示するための設定
- `spec/20-mockup-guide.md`：画面の役割と設計意図
- `spec/21-dummy-data.md`：見本データの説明

本番開発ではなく営業・説明用であるため、入力内容は保存されず、ボタンを押しても実際の取引は行われません。
