# ITTO モックアップガイド

## 目的

掲載会社への営業と投資家への説明で、利用者ごとの情報の見え方と、一棟不動産の販売がどの順番で進むかを確認する画面見本です。`spec/12-gamen-list.md` の全画面へ、最初の利用者選択または各ホームの画面一覧から移動できます。

## ファイルと画面の対応

| ファイル | 担当する内容 |
|---|---|
| `index.html` | C-01 利用者選択・デモ入口と、全画面共通の上部・下部 |
| `styles.css` | 全画面の配色、配置、パソコン・スマートフォン表示 |
| `app.js` | C-02〜C-03、B-01〜B-08、S-01〜S-06、A-01〜A-08、O-01〜O-05の表示、固定データ、画面切り替え |
| `.github/workflows/pages.yml` | GitHub Pagesによる画面見本の公開設定 |

画面を1ページずつ別ファイルにせず、利用者の立場と画面番号に応じて表示を切り替えています。これは、`index.html` を開くだけで全画面を見られ、営業中に立場を素早く切り替えられるようにするためです。

READMEの「見本画面を開く」は、`moto7070` から権限譲渡された後の所有者 `dexel1114` のGitHub Pages公式URLです。2026年7月31日に、無料で公開するため、見本画面だけでなく仕様資料を含む保存場所全体を公開するA案に事業責任者が決定し、同日に見本画面の表示まで確認しました。公開設定は譲渡先で有効にし、外部の確認サービスは使用しません。変更がメインの保存先へ取り込まれた後、画面への反映には数分かかる場合があります。

## 主な画面の役割と設計意図

- **利用者選択：** 買主・売主・仲介会社・ITTO運営の情報範囲を混同せず説明する入口です。
- **物件詳細：** 販売段階、物件概要、公開資料、現在価格を一画面で確認します。買主に公開しない個人情報は見本データにも含めません。
- **オファー入力：** 確定した価格・資金・融資・時期・希望条件を並べ、オファー期間中に成約しないことを明記しています。
- **入札・監視：** 入札中と障害停止中の見え方を同じ情報構造で比較できます。停止時の残り時間から再開する方針を表示します。
- **条件比較：** 買主を匿名番号で示し、落札価格だけでなく資金方法や決済時期を横並びで比較します。落札者を自動指名しないことも明記しています。
- **販売履歴：** オファー、入札、落札、優先交渉、成約を時系列で分け、落札と成約が別の出来事であることを示します。
- **各立場の補助画面：** 審査、通知、問い合わせ、資料、内部コメントなどは、一覧と状態表示によって情報の範囲を確認できます。実際の送信や外部サービス連携は行いません。

## 操作できる範囲

- 利用者の立場、各画面、物件詳細を切り替えられます。
- 入力欄や選択肢を操作し、確認ボタンを押せます。
- ボタン操作後は、実処理をしないデモであることを画面右下に表示します。
- データは再読み込みすると初期状態に戻ります。

## 仮置きした箇所

確定していない具体値や外部サービス名は画面に置いていません。本番開発まで保留されている以下の項目は、状態だけを表現しています。

| 保留事項 | モックアップでの表現 |
|---|---|
| 本人確認・通知の外部サービス | 「審査待ち」「承認済み」「通知済み」などの状態だけを表示 |
| データの保存期間 | 履歴は表示するが、保存期限や削除日は表示しない |
| 1ファイルの容量上限 | 見本ファイルの容量は表示するが、上限値や警告は表示しない |
| 同時利用者数・障害当番 | 停止状態と再開予定の案内だけを表示 |

したがって、未確定仕様を推測した「※仮」の機能はありません。物件名、価格、所在地、日時、会社名などの営業説明用データはすべて架空です。

## 2026年7月31日の買主サイト修正

公開サイトは買主専用に変更し、利用者を選ぶ入口を廃止しました。楽待・健美家・SUUMOのように、まず物件を探せる構成を参考にしつつ、ITTO独自の販売段階が伝わるよう「入札予定」「オークション中」「終了」を縦の3区分で表示しています。トップは販売状況、検索画面は物件種別と区・市町という役割に分け、どちらもチェックボックスで複数条件を選べます。売主・仲介会社・ITTO運営の画面は公開サイトには置かず、将来の管理画面として分離します。

2026年8月3日に公開URLで以前の画面が表示されたため、`index.html` から読み込む画面部品に更新番号を付けました。これにより、閲覧端末に以前の画面が残っていても、今回の買主向け画面を読み込み直します。

## 2026年8月3日の実需向け修正

買主トップの物件例は、土地・戸建て・区分マンションを中心とし、価格を2,850万円から1億4,500万円の範囲へ変更しました。一棟収益物件は6件中1件だけとし、一覧の比較項目も利回りではなく面積へ変更しています。また、実需の買主に投資専用サービスと誤解されないよう、トップの「投資機会」を「住まいと土地」へ変更しました。

## 2026年8月7日の検索条件追加

楽待などの不動産検索サイトで利用者が最初に地域または沿線を選ぶ構成を参考に、「都道府県から探す」と「沿線から探す」を切り替える入口を追加しました。さらに土地面積と駅徒歩で絞り込めます。土地以外の一覧には新耐震・旧耐震を表示し、マイページ表記へ統一しました。

土地面積のプルダウンは50㎡・75㎡・100㎡、以降50㎡ごとに500㎡までを選べます。駅徒歩は1分から20分まで1分刻みです。大まかな固定区分ではなく、買主が希望条件に近い下限・上限を選べるようにしています。

## 2026年8月7日の地域・沿線・物件拡充

市区町村は東京23区と多摩地区の2つの折りたたみ欄に分け、全区市町村をチェックボックスで選べます。沿線もJR・東京メトロ・都営地下鉄・私鉄に分け、東京都内を広く探せるようにしました。見本物件は6件から15件へ増やし、地域・物件種別・販売状況・耐震区分の組み合わせを比較できます。

## 2026年8月7日のトップデザイン修正

トップでは説明文よりも「不動産オークションのITTO」というサービス名を大きく表示します。濃い緑で画面全体を覆う構成から、白を基調に明るい青緑と淡い金色を組み合わせた構成へ変更し、実需の買主が入りやすい印象にしました。マイページは「検討中」ではなく「お気に入り」と表示します。
