# ITTO 用語集

## この文書の目的

ITTOの画面、説明資料、将来の開発で同じ言葉を同じ意味で使うための用語集です。特に、**落札は取引の成立ではなく、成約とは別の記録**であることを全員で統一します。

## 販売の流れに関する用語

| 用語 | ITTOでの意味 | 混同しないための注意 |
|---|---|---|
| 掲載 | 仲介会社が物件情報、写真、資料を買主が閲覧できる状態にすること。 | 売主は内容を確認するが、登録・変更はしない。 |
| 準備期間 | オークション開始前の約1か月。買主が内覧、融資相談、資金計画を進め、オファーを提出する期間。 | この期間中に成約はしない。 |
| オファー | オークション開始前に買主が提出する購入意向。購入希望価格と購入条件を含む。 | 売買の申込みをサイト内で承諾して成約させる機能ではなく、需要確認に使う。 |
| 開始価格 | オークションが始まるときの価格。 | ITTOでは、準備期間中の最高オファー額をそのまま開始価格にする。 |
| 入札 | オークション期間中に買主が購入希望価格を提示すること。 | オファーは開始前、入札は開始後に行う。 |
| 即決価格 | オークションをその場で落札できるよう、売主が出品時に設定する価格。 | 開始から24時間後に条件を満たす場合だけ公開する。 |
| 即決 | 公開された即決価格で買主が即時の落札を選ぶこと。 | 即決で決まるのは落札であり、契約・決済完了を意味しない。 |
| 不成立 | オークションで落札者が決まらなかった状態、または契約・決済に至らなかった結果。 | どの段階で不成立になったか分かるよう、結果と理由を記録する。 |
| 優先交渉 | 売主が価格と条件を比較して特定の買主を選び、その買主と優先的に交渉する段階。 | 落札者が必ず選ばれることや、取引成立を意味しない。 |
| 失効 | 優先交渉に選ばれた買主が、通知から48時間以内に必要な回答をせず、優先交渉の権利を失うこと。 | 通知を読んだだけでは回答にならない。 |

## 落札と成約

| 用語 | ITTOでの意味 | 記録する時期・内容 |
|---|---|---|
| **落札** | オークションで最高額の入札者が決まること。**取引の成立ではない。** | オークション終了時に、落札者、落札価格、日時を記録する。 |
| **成約** | 売買契約と決済が完了し、取引が実際に成立すること。**落札とは別の出来事である。** | 契約・決済の完了後に仲介会社が、成約価格、成約日、成約相手を登録する。 |
| 落札価格 | オークション終了時に落札者が提示していた価格。 | 後の条件調整などにより成約価格と異なる可能性があるため、成約価格で上書きしない。 |
| 成約価格 | 契約・決済が完了した実際の売買価格。 | 仲介会社が成約結果として登録し、落札価格とは別に保存する。 |
| 落札者 | オークションで最高額を提示し、落札した買主。 | 契約・決済が完了するまでは成約相手とは限らない。 |
| 成約相手 | 契約・決済を完了した買主。 | オークション不成立後に、オファーから優先交渉へ進んだ買主の場合もある。 |

### 使い分けの例

- 正しい表現：「Aさんが8,000万円で**落札**した。その後、契約と決済が完了し、7,950万円で**成約**した」
- 誤った表現：「オークションで落札されたので、取引が成約した」

## 利用者と連絡に関する用語

| 用語 | ITTOでの意味 |
|---|---|
| 買主 | 物件を検討し、審査承認後にオファーや入札を行う利用者。優先交渉に選ばれるまでは匿名で表示する。 |
| 売主 | 物件の所有者。掲載内容を確認し、価格と条件を比較して優先交渉する買主を選ぶ。買主に対しては匿名で表示する。 |
| 仲介会社 | 物件情報・資料の登録、問い合わせ対応、内部コメントの投稿、契約・決済の支援、成約結果の登録を行う宅地建物取引業者。 |
| ITTO運営 | 会員審査やサービス運営を行う担当者。仲介、契約、決済は行わない。 |
| 物件の問い合わせ | 売主・買主が、サイト内から掲載仲介会社へ物件について確認するための連絡。 |
| 内部コメント | 仲介会社が投稿し、売主とITTO運営が閲覧する関係者向けの記録。買主は利用できない。 |
| 定型通知 | オークション開始や優先交渉の指名など、決まった内容を買主へ知らせる連絡。買主との自由な文章による交渉には使わない。 |

## 審査・開発に関する用語

| 用語 | ITTOでの意味 |
|---|---|
| MVP | 最初に提供する必要最小限の範囲。ITTOでは、オークション、定型オファー、条件比較、優先交渉する買主の選択、履歴保存を指す。 |
| モックアップ | 掲載会社への営業や投資家への説明に使う、画面の見た目と操作イメージ。実際の審査、通知、入札、契約、決済は動かない。 |
| KYC | 本人確認のこと。買主が実在する本人であることなどを確認する手続き。利用する外部サービスは本番開発まで保留する。 |
| 宅地建物取引業の免許 | 仲介会社が適法に不動産取引を扱うための免許。ITTO運営が会社情報とともに確認する。 |
| API連携 | 外部サービスとデータを自動で受け渡す仕組み。今回のMVPでは大規模な外部連携を作らず、物件情報は手入力する。 |
