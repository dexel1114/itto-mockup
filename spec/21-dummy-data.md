## 目的

モックアップに表示する架空データと、本番で必要になるデータを区別する資料です。現在のデータはすべて `app.js` 内の固定値で、保存や外部送信は行いません。

## モックアップのデータ

### 物件

| 項目 | 例 | 本番での用途 |
|---|---|---|
| 物件ID | `1` | 物件を重複なく識別する |
| 物件名 | THE RESIDENCE 白金台 | 一覧・詳細・履歴の見出し |
| 所在地 | 東京都港区白金台 | 物件の場所を示す |
| 物件種別 | 土地／戸建て／区分マンション／1棟アパート | 物件を分類する |
| 現在価格 | 2,850万円〜1億4,500万円 | オファー、開始価格、最高入札額を状況別に示す |
| 販売状況 | 準備期間／オークション中／優先交渉中 | 現在できる操作を分ける |
| 残り時間 | 18時間42分 | 入札・回答期限までの時間を示す |
| オファー総数 | 12件 | 他の買主の内容を伏せて関心度だけ示す |
| 写真URL | 見本写真の外部URL | 営業画面の物件写真を表示する |

### オファー・入札・優先交渉

| データ | 含める項目 |
|---|---|
| オファー | 匿名買主番号、購入希望価格、資金方法、融資状況、契約・決済時期、希望条件、任意補足、提出日時 |
| 入札 | 匿名買主番号、入札額、入札日時、最高額かどうか |
| 優先交渉 | 指名された匿名買主番号、通知日時、48時間の回答期限、回答内容、回答日時、失効状態 |

### 履歴・成約

落札には落札者、落札価格、落札日時を持たせます。成約には成約相手、成約価格、成約日を別に持たせ、落札記録を上書きしません。不成立の場合は、オークション段階か契約・決済段階かと、その理由を記録します。

### 会員・連絡

- 買主：匿名買主番号、会員審査状況。氏名は優先交渉で必要になった後だけ共有します。
- 売主：買主には匿名で表示し、所有物件と掲載確認状況を関連付けます。
- 仲介会社：会社名、免許番号、審査状況、担当物件を持ちます。
- お知らせ：種類、対象者、対象物件、通知日時、確認状況を持ちます。自由な交渉文は持ちません。
- 問い合わせ：送信者の立場、対象物件、掲載仲介会社、質問、回答、各日時を持ちます。
- 内部コメント：対象物件、投稿した仲介会社、本文、投稿日時を持ち、買主には公開しません。

## 本番で追加して管理する情報

- 物件の詳細情報、写真30枚まで、資料種類ごとに10ファイルまでの実ファイル
- 会員の連絡先、審査に必要な情報、権限、利用停止状態
- 各操作を行った人と日時、通知の送信・確認結果
- オークションの開始・終了・停止・再開日時と、停止時の残り時間
- 優先交渉後に共有した買主情報の範囲と共有日時
- 契約・決済完了後の成約結果または不成立理由

保存期間、1ファイルの容量上限、本人確認・通知に利用する外部サービスは未確定のため、データ項目に具体値やサービス名を設けていません。
